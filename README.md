# Aeon OS Berk — Web Demo

**▶ Try it live: https://aeon01100101.github.io/aeon-os-berk-web/**

A clickable toy copy of **Aeon OS Berk** that runs entirely in your web browser.
No install, no downloads — just open the page and poke around the desktop.

## What you can do in the demo

- Press the big green **start** button and open apps from the menu
- Drag windows around, make them big, small, or close them
- **Aeon Store** — tap *Get* and watch an app arrive
- **D0S** — a friendly DOS-style terminal (try typing `HELP`)
- **Music, Pictures, Files, TV, Write, Updates** — little working demos
- **Games** — paint a tiny block world in the AeonCraft demo
- Shut it down from the start menu… then turn it back on
- **It remembers you!** The demo has a little hard drive inside your browser:
  letters you save in Write, apps you get in the Store, and your AeonCraft
  world are all still there when you come back. The drive lives only on your
  machine — nothing is uploaded anywhere (This PC shows how full it is).
  Cookies were too tiny to hold files, so the drive uses the browser's
  bigger built-in storage box — same idea.

## What this is (and isn't)

This is a **simulation for trying the look and feel**. The real Aeon OS Berk is a
complete operating system — based on Linux Mint 22.3, with a Windows XP-style
desktop that a 1st grader can use, a firewall that's always on, automatic
checked updates, and the Aeon Store as its one and only app store.

**Get the real thing (free):** https://archive.org/details/aeon-os-berk-1.0.1
**How it's made:** https://github.com/aeon01100101/project-berk

## Tech

Plain HTML, CSS, and JavaScript — no build step, no frameworks, no tracking.
The wallpaper and colors are the real ones from the Berk XP theme.
